skill 0.1.0 is the first release of a Ruby command line for Agent Skills. It installs skills from GitHub repositories, plugin marketplaces, and local folders into RubyLLM's `app/skills` and the folders Claude Code, Codex, Cursor, and more than 70 other agents read, records each skill's commit in `skills.lock`, and shows you what changes before it updates anything.

```sh
gem exec skill add anthropics/skills@pdf
```

![gem exec skill finds the pdf skill on skills.sh and installs it globally from the home folder, then into app/skills of a new Rails app that uses RubyLLM](https://github.com/crmne/skill/raw/v0.1.0/docs/demo.gif)

It needs Ruby 3.1 or newer and nothing else. `gem exec` needs RubyGems 3.5 or newer (Ruby 3.3 ships it); with an older RubyGems, `gem install skill`.

## New

### Install skills where your app and agents read them

```sh
skill add anthropics/skills --list
skill add anthropics/skills@pdf,xlsx
skill add acme/skills#v1.2.0 --all --agent rubyllm
```

`skill` reads the same sources as `npx skills`: `owner/repo`, `owner/repo@skill`, `owner/repo/path`, a branch, tag, or commit after `#`, GitHub addresses, and local folders. It finds skills in the usual folders and in Claude Code, Codex, and Cursor marketplace files, and installs into every folder your project shows signs of using: `app/skills` for RubyLLM, `.claude/skills` for Claude Code, `.agents/skills` for Codex, Cursor, and others. `--agent`, `--dir`, and `--global` choose instead. By @crmne

### A lockfile with commits

`skills.lock` records each skill's source, ref, commit, path in the repository, digest, and folders. It is sorted and carries no timestamps, so it merges cleanly. By @crmne

### Updates that wait for your yes

```sh
skill update
```

A commit never moves. A tag that someone moved is called out. A branch shows its commit range, a compare link, and every file added, changed, or removed, and applies only after you answer yes or pass `--yes`. An unchanged repository costs one small request and no download. By @crmne

### Search skills.sh

```sh
skill find rails
```

Searches the same directory `npx skills` uses and prints the command that installs each result. By @crmne

### Safe by default

Every `SKILL.md` is checked with RubyLLM's rules. Archives with paths that leave their folder are refused, links are never written, sizes are capped, executable bits are dropped unless you pass `--keep-executable`, installs are swapped in atomically, and skills you edited or installed by hand are replaced only with `--force`. By @crmne

## Known limitations

* **GitHub and local folders only.** GitLab, other git hosts, and direct archive URLs are not supported yet.
* **Plugins in other repositories are listed, not installed.** When a marketplace points a plugin at another repository, `skill add --list` names it; add that repository on its own.
* **Copies, not symlinks.** Each folder gets its own copy, unlike `npx skills`' default of one copy with symlinks.
* **Windows is untested.**
* **No interactive picker.** Choose skills with `@name`, `--skill`, `--plugin`, or `--all`.
